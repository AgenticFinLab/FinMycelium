# 4 · 图例与视觉标记

[总览](0-overview.md) · [关系与 Context](2-relations-and-context.md) · [页面与证据](3-view-and-evidence.md) · [示例与验收](5-examples-and-checks.md)

本章是自动 HTML 的读图索引。同一种线型可出现在卡片边框、时间刻度或对象之间，读法由它附着的位置、颜色、文字及两端共同决定。下列色值对应当前默认主题，调整主题时应同步维护卡片和图例，让读者能靠形状和文字辨认同一含义。

## 4.1 页面上的对象

| 对象 | 可见标记 | 读者能查到什么 |
| --- | --- | --- |
| Event、Stage、Phase | 深蓝页标题为当前页名。页首的“人物 · 事件”打开 Event，Stage 标题打开 Stage，Phase 页签切页，当前页签为蓝底。选中跨页关系后，紫框指出目标页签。 | 所在事件、局面阶段、行为阶段及其记录。导航顺序不增加 Action 的先后关系。 |
| Action | 浅绿矩形（`#e2f0e6`），行动标题加粗。卡首显示 `A…`、已知时间或时间状态，有直接出处时可显示来源简称。 | 行动、执行者、对象、已记录的关系，以及当前 Phase 内哪些行动可确定先后。 |
| 人物、组织及其他实体 | 浅蓝圆形。组织用楼形，其余当前使用通用人物形，名称在下方。执行者列按记录标 `Focal person` 或 `Actor`，相关方标 `Related party`。 | 被记录的身份、代表谁、在哪一项行动里承担何种角色或仅被提及。其他实体的具体类型以图数据为准。 |
| Context | 矩形，首行列 `C…`、类别、已记录的时间。底色和边框表示本页作用范围，左侧色条表示内容类别。卡旁的谓词说明它如何与特定对象关联。 | 背景事实、视角、每条实际用途及各自的依据。 |
| Evidence | `Evidence` 区内的淡绿色卡（`#f0f6ee`），以 `EV…` 加原文片段辨认。 | 对应原文、定位与单一出处，详情中保留完整引文。 |
| Source | `Sources` 区内的浅蓝灰卡（`#f2f6fa`），以 `S…`、来源标题及已知发表日期辨认。 | 来源、原始链接和本 Event 从该来源引用的各段原文。 |
| Action 关系 | 有谓词的连线，可点线或标签。`R…` 指一条关系记录。 | 两端 Action、谓词、方向、获得方式及关系字段本身的证据。 |

`A / C / E / EV / S / P / ST / R` 分别是本图 Action、Context、实体、引文、来源、Phase、Stage、关系的显示简称。原始 ID 决定归属和追溯。卡面只摘取已有文字，过长用省略号，详情可读原完整陈述。右上角绿色 `S…` 是这条记录直接引用的来源简称，按来源去重。徽标数量不代表支持强度，嵌套角色、关系或推断前提的全部依据应从相应字段查看。

## 4.2 Context 的两套图例

| 本页作用范围 | 卡片底色与边框 | 页面表现 |
| --- | --- | --- |
| `Phase-wide` | 浅蓝 `#e0edfc`，深蓝实边 `#346994`，顶边加粗 | 多行动页使用共享区。单行动页的继承条件或约束卡在行动上方，卡内标明 `Phase-wide`。 |
| `Action-linked` | 奶油黄 `#fff0c9`，赭色细实边 `#ba944a` | 在有关行动附近。先读连接的谓词，再判断背景的作用。 |
| `Reference only` | 浅灰 `#f0f2f5`，灰色虚边 `#788594` | 位于 `Additional context`。本页无明确的 Phase 或 Action 适用关联，仍可有真实引文及实体提及。 |

| Context 内容类别 | 左侧色条 | 涵盖的事实 |
| --- | --- | --- |
| `environment` · Environment | 赭色 `#987226` | 行动所依赖或改变的外部条件，如制度、市场或组织环境。 |
| `relations` · Parties & relationships | 蓝灰色 `#52738b` | 相关人物与组织、角色以及当时的关系格局。 |
| `person_state` · Personal state | 玫瑰色 `#995668` | 焦点人物的目标、资源、限制、知识或信念。 |

范围图例 `Context scope` 只列本页出现的范围。有至少一个已知类别时，旁边的 `Context category (left stripe)` 展示三种类别供对照。两套图例在标题下方，窄屏可折行，图例色块不随图内缩放缩小。类别缺失时，卡上写 `Context`，详情示 `Not recorded`，不猜一种色条。`post_hoc` 另加 `Retrospective` 文字，其余视角可在详情查阅。比如，浅蓝卡配玫瑰色条，表示“整个 Phase 共享的主体状态”。该卡对某个 Action 的个别例外，要点开看适用记录。

## 4.3 连线与其他线型

| 在哪里看到 | 默认样式 | 准确读法 |
| --- | --- | --- |
| 两个 Action 之间，或 Action 与对端 Phase 页签之间 | 紫色 `#80589f` 实线 | 原始关系的 `basis` 为 `observed / asserted / derived`，且类型不为 `order_unknown`。按标签的起点、谓词、终点读。实线本身不保证先后、因果或内容已审核。 |
| 同样的两个端点 | 紫色短虚线 | `basis=inferred` 或谓词为 `order_unknown`。推断性的有向关系仍有箭头。`overlaps / order_unknown / joint_action` 为对称关系，一律无箭头，实虚由相同规则决定。 |
| 实体与 Action、Context 之间 | 蓝灰 `#607f9c` 实线 | `actor` 由实体指向 Action，`object` 由 Action 指向实体，`about` 由 Context 指向其提及的实体。`about` 的线较淡。 |
| Context 的适用关联 | 赭色 `#a18a51` 长虚线 | 始终按六种用途的语义方向读。即使一端是实体，`participation` 和 `knowledge-source` 也属于此线族。虚线在这里表达背景关联。 |
| 选中记录或字段后，来源、引文与所支持的对象之间 | 绿色 `#4f8270` 点线，末端有箭头 | `Source → Evidence` 表示收有该段引文，`Evidence → 对象或关系线` 表示该引文用于支撑所选陈述。初始视图隐藏溯源线。 |
| 卡片或区块的外框 | 参考背景为灰色虚框，共享背景为蓝色粗顶边 | 标明本页展示范围。外框没有起点和终点。 |
| Action 卡片下方的 `Possible window` | 带端标的灰绿色点状括线，无箭头 | 该行动可以发生在所示范围的任一处。`Time within day unresolved` 表示只确认到日。`Duration unverified` 表示已记录边界，区间内是否持续仍缺少对应的字段支持。 |
| Action 卡片下方的 `Duration` | 带端标的灰绿色实线，无箭头 | 行动本身有据持续于该区间。详情给出原始起点和排他终点。与另一条持续线部分重叠时，两行保留各自的范围。 |
| `Upper limit / Lower limit` | 短虚线，封口对齐已知界限的时间列 | `By` 卡在开放的左侧，右端标出最晚界限。`From` 卡在开放的右侧，左端标出最早界限。两者均包含界限日期，与同日其他行动的实际先后要另查依据。 |
| `Phase scope` | 淡灰虚线，两端开放 | 卡片显示 `Phase only` 或已知的外页相对锚点。线宽表示本页排布范围。行动发生窗口另有独立的双端括线。 |
| 多行动页的 `Action chronology`、`Relative order`、`Order disputed` | 有日历依据时刻度对齐行动，有内部先后的无日期链和有未决矛盾的行动分别标出 | 轴上、轴下均可读本 Phase 的行动。刻度间距随内容而定。[排布规则](1-action-layout.md) |
| 与关系标签相连的细短线、交叉的折线 | 标签引线较细，折点和交叉处没有节点卡 | 引线将标签对准已有关系，交叉和折点不另生成关系、参与方或汇合行动。 |

当前连线图例有五项，依次为 `Action links`、`Inferred / order unknown`、`Roles`、`Context` 和 `Evidence`。在有 Evidence 区的页面，图例位于该区标题旁。无 Evidence 区时的入口见[待讨论项](6-open-questions.md)。

仍可读取的旧记录可能缺少 `basis`。当前详情显示 `unspecified`，普通谓词会沿用实线外观。因此，判断依据时应查看关系详情中的实际取值。`derived` 的时间关系可用实线，其字段通过 `I` 说明推导前提。关系获得方式和字段支持模式是两个独立维度。

## 4.4 浏览、选中与返回

| 操作 | 画面变化 | 阅读含义 |
| --- | --- | --- |
| 悬停或以键盘聚焦卡片 | 本卡和有关连线加深，邻接卡保留强调，其他卡淡出。支持方向提示时，沿线可有短暂流动效果。 | 辨识当前端点。强调、淡化和动画不改变任何事实或支持方式。系统要求减少动画时保留静态箭头与文字。 |
| 读取共享 Context | 继承条件或约束的赭色虚线与谓词默认可见，同一引用共用一个谓词标签。选中卡片时，有效继承的行动另有蓝色轮廓和加粗底边。 | 点线或谓词可查原始 Phase 引用，点卡可对照继承、排除和未决。共享卡的实体提及线在聚焦该实体时展开。 |
| 选中关系或字段 | 关系与本页对应引文可高亮，绿色点线在可见端点间出现。详情可分别查看字段、引文和来源。 | 区分支持整条记录的材料与支持其中某个字段的材料。端点在视口外时，详情仍是证据入口。 |
| 查看跨页关系 | 紫框指向顶部对端页签。`Go to` 打开对端 Action，`Back to` 回到原 Action。 | 共享同一关系记录。双向浏览不会新增一条反向事实。 |
| 返回或关闭详情 | 详情内 `Back` 返回先前记录及展开字段，`Escape` 或 `Close` 回到图面。桌面详情在侧边，窄屏可移至下方。 | 区分跨 Phase 回程与字段追溯回程。悬停、键盘聚焦和点击均有可辨认反馈。 |

对象配色、线型及页签来自[自动 HTML 模板](../../finmy/person_epg/event/graph.html)，字段追溯、范围与类别文字来自[详情视图](../../finmy/person_epg/event/graph_inspector.js)。页面上的英文名称与图例以这两个入口为核对依据。
