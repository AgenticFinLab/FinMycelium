# 高盛事件的关系发现与独立复核

2026-11-17 至 11-18。关系阶段为 Action 和 Phase 关联适用的 Context，并建立有原文或可说明推断依据的 Action → Action 关系。以下实验固定上游输入，检查新增边的依据、方向和谓词。[同一输入的 Kimi 整图构建](person-build-reasoning.md)

## 先在一份材料和一个关系任务上验证

11 月 17 日固定 Kimi、接收器、材料和调用额度，更换了职责说明及上下文交付。在同一份 8,112 字符的材料上，两版均提取 3 个 Action、4 个 Context 和 1 条候选，各用 1 次调用。仅凭这份材料，尚看不出新提取说明改变了覆盖。

关系小试从同一张 26 行动的图中指派 6 个行动和 3 个 Phase。旧版与新版各用 2 次调用，分别消耗 146,736 和 147,868 tokens。通过结构检查的关系由 2 条增至 4 条，其中原候选之外的行动对由 1 对增至 2 对。新版从晚间访谈和当天下午的公告中识别了投资决定与公开评价的先后。两版均只完成 7/9 项 Context 指派，较晚发生的事项仍被错误地用于较早的 Phase。可在 FinMycelium 本地 `output/person-event-optimization-20261117/manifest.json` 查到该次试验。以下整批审查另有独立的固定输入。

## 固定实际请求，只更换证据分配程序

在两个已保存的首批关系请求上，固定行动、Phase、候选、原文、系统提示词和 240,000 字符上下文预算。较早的程序先为每个行动分配完整直接引文，再按行动与 Phase 轮流加材料。当前程序同样保障行动覆盖，并提前放入能证明候选关系类型的原文。此次比较在本地重建请求，没有运行模型。

| 快照 / 本批行动 | 有直接引文的行动，早期 → 当前 | 已交付的候选连接引文 | 所有随包引文条数 | 用户消息字符 |
|---|---:|---:|---:|---:|
| 22 / 22 | 22 → 22 | 8/8 → 8/8 | 47 → 47 | 154,347 → 156,938 |
| 26 / 25 | 25 → 25 | 6/12 → 12/12 | 29 → 33 | 156,818 → 156,896 |

在第二份快照，两版都让模型看到 25 个行动各自的依据。当前程序多交付了 6 段直接支持连接的原文，整条用户消息仅增加 78 字符。它证明所需材料进入了请求，模型对这些材料的解释仍需另查。当前重建的两个请求均逐字段匹配已保存请求。[较早的分配程序](https://github.com/AgenticFinLab/FinMycelium/blob/1f2311434f76de39630699f6269b6846bf905ed0/finmy/person_epg/event/context.py) · [当前分配程序](../../finmy/person_epg/event/context.py)

## 联合构建后，再作独立复核

两组先用 Kimi low 联合处理关系与 Context，关闭最后的整图修复。独立复核最多再调用两次 high：第一次只看行动、背景和已定位引文，第二次才看到已有边的名称、端点和方向。联合图与复核图分别保存。

| 固定条件与结果 | 22 个行动 | 26 个行动 |
|---|---:|---:|
| 来源 / 交接字符 | 25 / 89,952 | 19 / 82,244 |
| Stage / Phase / 已有候选 | 4 / 6 / 6 | 3 / 6 / 6 |
| 完成逐行动审查 / 送达候选连接引文 | 22/22 · 8/8 | 26/26 · 12/12 |
| 联合图关系 / 候选外新增行动对 | 9 / 3 | 12 / 6 |
| 行动增量 Context 引用 / Phase 背景引用 | 0 / 34 | 26 / 12 |
| 联合调用 / 累计模型时间 / 已回报 tokens | 5 / 8 分 10 秒 / 245,120¹ | 6 / 11 分 21 秒 / 347,450 |
| 独立盲读提出的关系 | 19 | 17 |
| 联合图 → 复核图关系 | 9 → 23 | 12 → 20 |
| 原边端点、方向和类型均保留 | 8/9 | 8/12 |
| 修订原边 / 新增边 | 1 / 14 | 4 / 8 |
| 复核后与最初候选的端点、方向和类型均相同 | 5/6 | 3/6 |
| Context 复核意见 | 标记 1 项 | 标记 2 项，另 1 项越出本轮范围而被拒收 |
| 独立复核调用 / 时间 / token | 2 / 13 分 43 秒 / 90,990 | 2 / 13 分 59 秒 / 105,804 |

¹ 有一次连接失败缺少用量。联合阶段的局部读取上限分别为 60 次 / 160,000 字符和 40 次 / 96,000 字符。独立复核无局部补读。两组的联合图和复核图均为 `partial`。22 行动组保留上游 4 项未处置记录；26 行动组最后一批有一条使用示例 ID 的关系被拒收。

**补回了什么。** 独立复核在两组中都找回了“2008 年投资先于 2009 年股东信”和“次年的披露延续同一持仓主题”。26 行动组还保留了“赎回预期先于收到还款”。两份复核都指出，公告列出的预定赎回日与已经完成赎回要分别表达。

**哪些新增边需要驳回或降级。** 22 行动组把“修约使无现金转换成为可能”改成 `overlaps`，签约或公告同日不足以证明当日实际完成行权。26 行动组保留了同一组的 `enables`，却把同日谈判与口头承诺从先后未知改成时间重叠。两组都尝试将先前拒绝多项救助请求写成被新投资打断的持续行为，同期材料能够直接说明的是先后。另一处把为多笔危机投资筹资具体归到高盛一笔，也超出了股东信的归属范围。

**采用决定。** 联合构建保留逐行动直接引文、连接证据和可检查的审查记录。独立复核能发现遗漏，也会把较弱但可靠的联系改成缺乏依据的强谓词。保留独立意见及其后继图供内容审核选择。另一次同事件的四臂实验比较了基线、均衡取证、主动关系发现和职责拆分，其联合组得到 10 条边、逐行动审查 26/26、状态为 draft。该实验与这里重建的 26 行动快照未验证为同一文件，不能把 10 与 12 的差额解释为某一改动的收益。[四臂实验的记录与结论](person-relation-joint-vs-split.md)
