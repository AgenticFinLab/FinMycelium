## 如何读这些数

- **搜索**记录候选、实际阅读、入选来源和交接字符。搜索结果页上的摘要、送达模型的原文、最终入图的引文是三个不同的计量对象。
- **构建**使用固定输入的哈希和运行 ID 对齐结果。模型时间累计每次调用，跨恢复的墙钟还包括等待。用量缺报时列出已回报的 token；金额需要服务端账单或明确的计价依据。
- **图质量**通过行动归属、阶段划分、引文和关系方向判断。`draft` 表示可以进入内容审核。`partial` 的原因要回到该次检查和处置记录查看。

关系实验另保留三份原始方法说明，分别记录[如何冻结并回放组织快照](person-relation-replay.md)、[如何分配行动证据](person-relation-evidence.md)和[如何检查关系发现与局部修正](person-relation-discovery.md)。其中的补丁名、压缩包名和命令对应当时的实验环境。报告中的运行 ID 可用于在本地运行目录查找原始请求、响应和检查点。
