# 启动与复核提示词

在能够访问实际 FinMycelium 和 EPG-dataset checkout 的会话中使用。开展事实研究时需要能打开公开网页和文档；仅作结构复核时，可用本地已有证据与脚本。路径、数量、研究范围和是否发布按本次任务填写。

## 初次建设或续跑

```text
按 skills/curate-event-dataset/SKILL.md 整理 {{data_root}}/event-epg。
本次从 {{空目录或现行快照}} 起步，目标为 {{总量或净增量}}。
研究范围是 {{主题、地区或期间，如有}}，优先补足 {{覆盖缺口，如有}}。
交付 {{所需文件及位置}}，说明来源支撑、已确认重复和待核事项。
```

## 合并、替换或编号迁移

```text
按 skills/curate-event-dataset/SKILL.md 比较 {{主表}} 和 {{比较表}}。
确认重复后按 {{保留、替换或合并策略}} 处理，目标数量为 {{行数}}。
采用 {{编号和排序规则}}，同步受影响的引用并核对前后差异。
保留 {{原字段、进度或审核例外，如有}}。
```

## 复核现行目录

```text
按 skills/curate-event-dataset/SKILL.md 复核 {{现行目录}}。
检查范围是 {{结构与引用、事实、重复、分类或接口}}。
将检查结果、实际修订及未决事项保存到 {{位置}}。
```

阅读[主说明](../SKILL.md)选择做法。首次学习可用[可运行案例](worked-example.md)练习，正式事实核验使用实际材料。
