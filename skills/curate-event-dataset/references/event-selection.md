# 哪些事件值得单独研究

`EPG-dataset/data/events/events.csv` 中的 3,000 条是用户已确认入选的基线，对应 `event1` 至 `event3000`。保留其身份，逐项核实和补全新版字段。以下标准用于选择新增事件，也用于澄清既有行的研究范围。基线覆盖 6 个领域、26 个类别；这些分类可用于寻找同类案例，数量分布不作为新增配额。

## 新增事件按自身的研究价值判断

FinMycelium 的研究目的是从分散的公开文档中重建具体事件的演进过程，形成可追溯的结构化时间线。对新增候选，先回答：**把已知材料按时间和行动联系起来，能帮助研究者理解什么？** 例如，一项影响服务运行的决定是如何作出的、其间采取了哪些措施、可观察到的结果如何变化。

- **研究价值。** 说清受影响的对象、已经发生的实质变化，以及值得追踪的问题。影响可体现在市场运行、治理决策、工程安全、公共服务等方面。新领域、新机制或局部事件同样适用。
- **过程重建价值。** 打开能够定位的公开原文，判断是否可围绕同一事项追踪行动、决定、状态转变或响应。单个决定也可以成为研究中心；其形成背景、实施或后果中有材料支撑的部分可纳入范围。标明事实、各方说法和待解问题，保留不确定的时间和因果关系。

原有 3,000 项提供整体选题尺度：对象具体、变化值得追踪、证据能够支撑过程研究。下方案例仅供理解粒度；无需逐案配对、提交参考 ID 或沿用既有事件类型。查重时检查的是同一现实事项是否已经登记。

## 对象、范围和证据

| 判断 | Codex 应能给出的具体回答 |
| --- | --- |
| **能辨认是哪一件事** | 指出发生了什么，以及能区分这件事的主体、对象、地点、时期、正式决定或编号。例如“2013 年 Nasdaq SIP 故障”可以定位；“交易所技术风险”还需缩小到具体事项。 |
| **能界定独立的研究范围** | 用一句话说明从哪个节点查起、追踪哪些行动、到哪个结果或已知节点为止。发现可能指向同一事项的已有记录时，核对双方对象和范围。新报道或同一公告的译本可补入已有行；相连事项若有各自可独立研究的行动、材料和边界，可以分别登记并标注关联。 |
| **有公开证据可核实** | 打开能定位的原文，指出具体文件、段落或记录支持哪项核心事实，例如事故记录、监管决定、法院文书或研究报告。若只查到传闻，继续补研；若已证实的是“启动调查”，可围绕调查立项，并将被调查的指控归于提出方。 |

## 用已入选案例校准边界

| 历史事件 | 对新增候选的启示 |
| --- | --- |
| `event2994` · Nasdaq SIP Outage of 2013 | 中断与恢复可以发生在同一天。只要功能变化、影响对象和处置过程能够查证，短时事件也值得独立研究。 |
| `event1389` · U.S. Farmland Price Boom and 1980s Bust | 跨年的经济过程也可收录。将对象限定到美国农地市场，将问题限定到这一轮上涨、反转及调整，便有可研究的边界。 |
| `event2879` · Grindr National Security Divestment Order | 一项具体处置决定可以成为事件中心。可追踪决定针对什么对象、如何影响所有权及如何落实。 |
| `event197` · 2021 Texas Power Crisis；`event1703` · Winter Storm Uri Natural Gas Supply Crisis outside Texas | 同一天气过程可以引出不同研究对象。应分别界定得州电力系统失灵和跨境天然气供应中断；仅出现共同的风暴名称不足以判重。 |
| `event2995` · Saint-Gobain Sika Takeover Governance Battle | 研究对象是收购中的控制权争夺及其和解。另一宗收购若只有例行公告和预定交割日期，尚缺值得独立重建的转折；若公开记录显示治理争议改变了交易进程，就有了具体研究问题。 |
| `event2882` · Dee Bridge Collapse | 局部工程事故也可形成研究案例。可追踪失效涉及哪个工程对象、调查如何判断设计问题。普通维护通报若只更新施工时间，更适合作为背景材料。 |

## 如何作决定

事件有明确研究问题，过程值得重建，且对象可定位、范围独立、核心事实有原文支撑时，按主表规范补齐必填字段并分配新编号。例行披露、周期性统计或常规日程即使资料齐全，若找不到实质变化及可研究的问题，就跳过。若材料只补充已登记事件的一步，就更新已有行。若已有值得追踪的迹象，但核心事实、范围或关键材料仍不清楚，暂存候选并记下待查问题。批次未达到预期数量时，按实际入选数交付。

不设统一的金额、伤亡、热度、持续天数、阶段数或报道篇数门槛。局部或持续中的事件可以入选，只要已发生的部分满足以上判断。结束日期、完整因果链及最终图可在后续研究中补全。示例沿用历史表中的选题，用于说明粒度；填写事实时仍按字段规范核对原文。
