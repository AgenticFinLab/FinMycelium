# 整理独立事件目录

从公开资料中找到可以独立研究的事项，为每条记录说明发生了什么、研究范围到哪里、哪些材料支持结论。将整理结果写入实际 EPG-dataset checkout 的 `event-epg/`。从零建设、续跑、复核与合并使用同一套字段和证据规则。任务差异写进[启动提示词](references/launch-template.md)。

## 研究单元与术语

| 单元 | 在目录中承担的作用 |
| --- | --- |
| 领域与类别 | 用于筛选和比较研究主题。同一类别可有多个事件，分类变化沿用事件 ID。 |
| 独立事件 | 围绕某项可识别的决定、项目、争议或事故，具有明确主体、时间或可说明的覆盖窗口，以及纳入、排除范围。它可以经历多个阶段。 |
| 逐对裁决 | 比较两个具体事项，记录同一事件、范围重叠、独立事项或仍待核。主表的 `duplicate_status` 从这份裁决派生。 |

采用三个判断问题。

- **具体事项。** 能否给出案号、项目号、正式名称或可区分的行动对象？同一公司、年份或机构只能提供检索线索。
- **过程连续性。** 公告、审查和后续决定通常可能属于一个过程。只有研究对象和可核验的边界确实不同，才分别登记。
- **可独立交付。** 下游能否据此说清楚要研究什么、期间多长、排除哪些相邻事项？日期缺失时保留原有精度，并把缺口写进审核。

[海堤许可示例](references/worked-example.md)演示怎样判断两个看似同名的记录。东岸建设许可与西岸监测许可属于一个港口计划，各自授权不同动作，应保留两个 ID 并登记范围重叠。换成同一份许可的多篇公告时，先核对原文所指的许可身份。具体规则见[来源、去重与终检](references/research-and-audit.md)。

## 输入与交付

用户可提供主题范围、现行目录、拟比较的另一张事件表、目标数量或验收标准。新建时按范围发现候选；续跑时先核对当前表、检查点、重复配对和待核结论。数量目标按任务设定。用户要求保持原行时，合并后的行数与证据审核状态分别报告。

| 产物 | 以什么为准 |
| --- | --- |
| [事件主表模板](assets/events.template.csv) | 事件定义、分类、实际进度、收录路径、重复标记。完整字段见[主表规范](references/catalog-spec.md)。 |
| 来源、事件–来源、整理决定 | 逐项记录材料、支持字段、身份去向及变更。格式见[文件契约](references/artifact-contract.md)。 |
| [目录首页模板](assets/event-catalog-readme-template.md)与[研究计划模板](assets/event-research-plan-template.md) | 提供导航，交代范围、证据缺口和待确认事项；数量从当前主表和审计复算。更新现有目录时沿用原结构和已有结论。 |
| 当前审计与验收 | 记录逐行事实、逐对裁决、源文件和审核哈希。划清结构检查、事实支持与接口验证的结论。 |

工作文档沿用项目已有语言或用户指定语言。双语事件名指向同一事项，保留来源标题、原始日期精度和可定位引用。新事件使用 `planned`，负责人和成果路径按实际工作填写。正式表中的协作状态以事件实际进展为准。

## 从研究到交付

1. **核对现状。** 根据任务选择新建、续跑或复核，冻结输入并定位权威主表。跨表合并、同量替换及授权改号按[迁移步骤](references/catalog-migration.md)处理。
2. **找原文并登记主张。** 用公开检索追踪名称、机构、日期和正式编号。打开材料，分别确认身份、时间和范围。每条来源保留实际读到的位置和支持字段。证据不足时明确未核范围。
3. **比较对象并复核分类。** 召回表内、本批及指定比较表中的候选，用原文裁决。新增分类要能与相邻类区分，记录理由和代表事件。分类报告同时说明原始标签计数口径和人工判断。
4. **更新关联并验收。** 以稳定 ID 对齐主表、逐对裁决、证据、来源与审核。同步重复标记后刷新行哈希，再按当前表核验候选、数量和引用。[运行手册](references/runbook.md)给出暂存、召回、复查和快照物化命令。
5. **交付及确认。** 报告实际新增、合并、替换、保留重复和事实未决。待发布快照的核验与正式发布分别执行。需要 FinMycelium 输入时按[接口说明](references/workbench.md)验证实际解析器。确认选中事件的范围和采用材料后再进入检索与构建流程，图验收另行记录。

## 包内资源与工具

`assets/` 提供模板和合成档案；`references/` 提供启动示例、业务规则和命令；`scripts/` 提供可执行的预检、合并、召回、审核、快照及导出工具。首次学习可直接运行[完整教学案例](references/worked-example.md)，对照它生成的各文件，再换成自己的材料。脚本可以检查结构与引用，事实和身份裁决由执行者依据原文登记。
